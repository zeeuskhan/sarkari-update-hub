# Sarkari Update Hub

Hindi-first information portal for government jobs, schemes, apprenticeships, internships, scholarships and public-service updates.

## Stack
- Vite + static HTML/CSS/JavaScript
- Lightweight client-side search and category filters
- Mobile-first responsive layout
- SEO metadata, structured data, robots.txt and sitemap

## Content and attribution
Initial summaries are independently written from publicly visible topic listings on https://www.apprenticeshipinternship.in/. The site does not reproduce full articles. Each update links to its source. Users should verify eligibility, deadlines and application details on the relevant official government portal.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
